COMMANDS

The syntax bar guides you as you type. The status bar displays warnings, errors, progress and results.

Add true when building or removing more than 1,000 blocks. Large commands may display a performance warning. Press ENTER again to proceed, or edit or close the command to cancel confirmation.

Press ESC to close commands, then ESC again to cancel a running command if possible. Blocks already placed or removed will remain changed.

X and Z are horizontal axes. Y is the vertical axis.

/fill x y z x y z id [true]

Fill the area between two block coordinates, including both corners. Enter a block ID to place blocks, or 0 to remove them.

EXAMPLE: /fill 0 0 0 4 0 4 green_lightest

Builds a 5×5 platform using green_lightest blocks.

/dither x y z x y z id id percentage [true]

Mix two blocks in an evenly distributed pattern. Percentage determines the approximate amount of the second block, from 0 to 100. Use 0 as a block ID to remove blocks.

EXAMPLE: /dither 0 0 0 7 0 7 white_lightest black_darkest 50

Creates an evenly mixed black and white platform.

/gradient x y z x y z id id x|y|z [true]

Build a transition between two color blocks along the chosen axis, from the first coordinates toward the second, using available catalog colors.

EXAMPLE: /gradient 0 0 0 9 0 4 red_normal blue_normal x

Creates a red-to-blue gradient along the X-axis.

/checker x y z x y z id id size [true]

Build alternating squares or cubes of the specified size. Use 0 as a block ID to remove blocks.

EXAMPLE: /checker 0 0 0 7 0 7 white_lightest black_darkest 2

Creates a black and white checkerboard with 2×2 squares.

/border x y z x y z id thickness [true]

Build a border or hollow structure inward from the selected boundaries, leaving the interior unchanged. If the border is too thick to leave an interior, the entire area is filled. Use 0 to remove blocks.

EXAMPLE: /border 0 0 0 6 0 6 green_lightest 1

Creates a 7×7 border, 1 block thick, using green_lightest blocks.

/stripe x y z x y z id id size x|y|z [true]

Build alternating stripes or layers of the specified width along the chosen axis. Stripes stop at the selected boundaries. Use 0 as a block ID to remove blocks.

EXAMPLE: /stripe 0 0 0 7 0 7 red_normal white_lightest 2 x

Creates alternating red and white stripes, 2 blocks wide, along the X-axis.

/noise x y z x y z id id percentage [true]

Randomly mix two blocks. Percentage determines the chance of placing the second block, from 0 to 100. Use 0 as a block ID to remove blocks.

EXAMPLE: /noise 0 0 0 7 0 7 green_normal green_dark 25

Creates a green platform with randomly distributed darker blocks.

/line x y z x y z id width height [true]

Build a straight or diagonal line between two block coordinates. Width determines its horizontal thickness, while height extends upward. Use 0 to remove blocks.

EXAMPLE: /line 0 0 0 8 4 8 green_lightest 2 1

Creates an ascending diagonal line, 2 blocks wide and 1 block tall, using green_lightest blocks.

/circle radius height id h|s [true]

Build a hollow circular wall (h) or solid cylinder (s) from your feet upward. The minimum radius is 2 blocks.

EXAMPLE: /circle 5 4 green_lightest h

Builds a hollow circular wall with a radius of 5 blocks and a height of 4 blocks using green_lightest blocks.

/square distance height id h|s [true]

Build a hollow square wall (h) or solid square prism (s) from your feet upward. Distance determines how many blocks the square extends in each horizontal direction from its center.

EXAMPLE: /square 5 4 green_lightest h

Builds an 11×11 hollow square wall, 4 blocks tall, using green_lightest blocks.

/sphere radius id h|s [true]

Build a hollow sphere (h) or solid sphere (s) centered at your feet. The minimum radius is 2 blocks. Move high enough to prevent the sphere from extending below ground.

EXAMPLE: /sphere 5 green_lightest h

Builds a hollow sphere with a radius of 5 blocks using green_lightest blocks.

/pixelart width|auto colors|blackwhite flat|wall [true]

Build an image using colored blocks (colors) or shades of black, gray and white (blackwhite). Enter a width of at least 3 blocks to resize the image proportionally, or auto to keep its original size. Using auto requires true.

Build horizontally at your feet (flat) or vertically in front of you (wall). Transparent areas are skipped.

EXAMPLE: /pixelart 16 colors wall

Builds a 16-block-wide colored image as a vertical wall.

/teleport x y z

Move to the specified block coordinates. Coordinates must be whole numbers between −10,000 and 10,000. Your destination must be unoccupied and at or above ground.

/spawn

Return to your starting position if it is unoccupied.

/new

Reset your world by following the confirmation instructions. This replaces your current world and its autosave.

/save [name]

Download your world as a .bound file. Enter a filename without its extension, or leave it blank to save as world.bound.

EXAMPLE: /save myworld

Downloads your world as myworld.bound.

/load

Open a .bound file to replace your current world with a previously saved world.

/screenshot [name]

Download a screenshot of your current view without the interface. Enter a filename without its extension, or leave it blank to save as screenshot.png.

EXAMPLE: /screenshot mybuild

Downloads your screenshot as mybuild.png.

/map x z x z [name]

Download a top-down PNG image of the selected area, including both corners. Each pixel represents the color of the highest block at that position. Areas without blocks are transparent. Enter a filename without its extension, or leave it blank to save as map.png.

EXAMPLE: /map 0 0 15 15 mymap

Downloads a 16×16 image of the selected area as mymap.png.
