COMMANDS

/fill x y z x y z id [true]

Fill the area between two block coordinates, including both corners. Use IDs 1–56 to choose a block, or 0 to remove blocks. The limit is 500 blocks unless you add true.

EXAMPLE: /fill 0 0 0 4 0 4 41

Creates a 5×5 platform of block 41 at coordinates 0, 0, 0.

/save [name]

Download your world as a .bound file. Optionally enter a name, or leave it blank to save as world.bound.

EXAMPLE: /save myworld

Downloads your world as myworld.bound.

/load

Open a .bound file to load a saved world. This replaces your current world.
